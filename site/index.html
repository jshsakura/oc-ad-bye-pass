What it does

유튜브 광고
재생 전과 중간에 붙는 광고를 영상 데이터에서 미리 걷어냅니다. 플레이어가 광고를 아예 받지 않기 때문에, 건너뛸 것도 남지 않습니다.
다른 사이트
알려진 광고·추적 도메인으로 나가는 요청을 차단하고, 남은 광고 자리는 보이지 않게 숨깁니다.
사이트별 끄기
화면이 깨지는 사이트가 있으면 확장 아이콘을 눌러 그 사이트만 끄실 수 있습니다. 하위 도메인도 함께 꺼집니다.
규칙 자동 갱신
차단 규칙은 확장과 따로 관리합니다. 유튜브가 화면을 바꿔도 다시 설치하실 필요가 없습니다.
탭을 옮겨도 계속 재생
유튜브는 화면이 가려지면 스스로 재생을 멈춥니다. 그걸 막습니다.
아이폰에서 홈으로 나가는 경우는 다릅니다. 그건 WebKit 이 엔진 안에서 비디오를 세우는 것이라 웹페이지가 손댈 수 없습니다. 대신 두 갈래가 있습니다 — 나가기 전에 작은 창(PiP)으로 넘겨두면 계속 재생되고, 이미 멈췄다면 제어센터의 재생 버튼으로 이어집니다. 그 버튼이 듣도록 이 확장이 미디어 세션을 걸어 둡니다.
화면 속 화면(PiP)
유튜브가 모바일 웹에서 PiP 를 막아 두었습니다. 플레이어에 버튼이 붙습니다.
아이폰에서 나가고도 계속 들으려면 이 방법뿐입니다. 작은 창에 있는 동안은 시스템이 재생을 유지하거든요. 다만 iOS 는 전체화면 상태로 나갈 때만 작은 창으로 넘겨줍니다 — 그 전환 자체는 iOS 가 하고, 확장이 하는 일은 한 번의 탭으로 그 상태를 만들어 주는 것입니다.
계정 없음 · 서버 없음
모든 처리가 브라우저 안에서 끝납니다. 밖으로 나가는 데이터는 없습니다.
On YouTube
Ads before and during a video are cut out of the response. The player never receives them, so there is nothing left to skip.
Everywhere else
Requests to known ad and tracking domains are blocked, and the leftover ad slots are hidden.
Off switch per site
If a page breaks, click the icon and turn it off for that site only — subdomains included.
Rules update themselves
The blocking rules live apart from the extension. When YouTube changes its markup, the rules follow without a reinstall.
Keeps playing across tabs
YouTube pauses itself when its page is covered. This stops that.
Leaving the app on iPhone is a different thing: WebKit stops the video inside the engine, where no page can reach. Two ways round it — hand the video to a small window before you go and it keeps playing, or press play in Control Centre once it has stopped. The extension wires the media session so that button reaches the video.
Picture-in-picture
YouTube opts its mobile player out of picture-in-picture. A button is added.
On iPhone the video has to be fullscreen when you leave — that hand-off is iOS's own, and what the extension does is get you into that state in one tap.
No account, no server
All of it happens inside your browser. Nothing is sent anywhere.

ORION BETA

아이폰에서 확장 프로그램을 쓸 수 있는 브라우저는 Safari와 Orion, 두 가지입니다.
Safari는 확장을 앱으로 감싸서 매주 다시 서명해야 하지만, Orion은 zip 파일을 그대로 받아 설치합니다. 기간 만료도 없습니다.

Only two browsers on iPhone can run extensions: Safari and Orion.
Safari needs the extension wrapped in an app and re-signed every week. Orion takes the zip as it is, and it never expires.

그래도 안 되면 앱 스위처에서 Orion 을 완전히 닫고 다시 해 보세요. 계속 실패하면 이슈로 알려 주세요.

To check that it works, play a video.
If nothing runs before the video starts, it is working.

Ads disappearing from the feed does not prove much.
Those are blocked a different way and almost always go.

This button downloads the Orion build — a different file from the Chrome one below. Orion does not implement Chrome's network blocking, so that part is left out (276KB). YouTube blocking is unchanged; elsewhere ad requests go out but the ad slots are still hidden.

"Extensions Error / Something went wrong" is not the file. Extension installation in Orion is still in beta and fails often. Chased to the end on a real device, one thing fixed it.

Clear Orion's cache in its settings. Then swipe the old copy away in Extensions and pick the zip with +. If a later version sticks at the same place, clear the cache again.

If it still refuses, close Orion from the app switcher and try once more. If it keeps failing, tell me in an issue.

Orion 에서는 "다른 사이트"가 숨김만 됩니다. Orion 이 크롬의 네트워크 차단 기능을 구현하지 않아서, 광고 요청은 나가되 광고 자리는 보이지 않습니다. 유튜브 차단은 아무것도 빠지지 않습니다.

Brave · Vivaldi 는 크로미움 계열이라 Chrome 과 같은 파일로 동작할 것으로 보지만, 직접 확인하지는 않았습니다.

Safari 는 확장을 앱으로 감싸 서명해야 해서 접었고, Firefox 는 매니페스트가 달라 그대로는 안 됩니다. 안드로이드 Chrome 은 확장 자체를 지원하지 않습니다.

On Orion, "elsewhere" is hiding only. Orion does not implement Chrome's network blocking, so ad requests go out but the slots stay invisible. Nothing is missing from the YouTube side.

Brave and Vivaldi are Chromium, so the Chrome package should work there — untested.

Safari needs the extension wrapped in a signed app, which was dropped; Firefox has a different manifest; Chrome for Android supports no extensions at all.

Filter List

차단 규칙은 확장 코드와 따로 관리합니다.
유튜브를 열 때마다 확장이 최신 규칙을 확인하기 때문에, 규칙이 바뀌어도 다시 설치하실 필요가 없습니다.

The blocking rules are kept apart from the extension code.
The extension checks for new ones whenever you open YouTube, so a rule change never means reinstalling.
